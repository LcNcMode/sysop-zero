# engines/

Reusable code that prods build on: tiny synths, tracker players, effect libraries,
packers, intro frameworks. **MIT** (see `LICENSE`), so it can be used by any prod
regardless of the prod's own license.

One folder per engine: `engines/<name>/` with a `README.md` (what it does, API, size cost)
and a `LICENSE` header if it differs. Credit the engine in your prod's `nfo.txt`.
