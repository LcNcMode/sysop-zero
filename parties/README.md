# parties/

One file per party: `parties/<year>-<slug>.yaml`. A prod joins a party by setting
`party: <year>-<slug>` in its `prod.yaml`, or through a **Compo entry** issue.

```yaml
name: Sysop Zero Party 2027
date: 2027-08-01
location: online
compos: [demo, intro-4k, intro-64k, music, gfx]
rules:
  provenance: declared     # every entry declares human | ai | hybrid; no separate AI ghetto
  deadline: 2027-07-25
```
