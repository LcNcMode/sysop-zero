## Glossary

| word | meaning |
|---|---|
| **prod** | a finished release: demo, intro, music or graphics |
| **nfo** | the text file that ships with a prod: credits, greetings, controls |
| **handle** | your scene name. The only name used here. |
| **group** | the crew behind a prod (or your handle, for solo prods) |
| **compo** | a competition at a party, voted on by the audience |
| **intro** | a size-limited prod: 4k = 4 096 bytes, 64k = 65 536 bytes |
| **provenance** | who made it: `human`, `ai` or `hybrid` |
| **declared** | what you say about your prod, in `prod.yaml` |
| **observed** | what CI measures in your prod folder |
| **drift** | a difference between declared and observed. A note to fix or explain, not a verdict. |
| **greets** | shout-outs to other sceners. Mandatory. |
